# VaKoLink-Client

## Исходная сборка

- Основа клиента — официальный v2rayN, тег `7.25.6`, коммит `1883178b5f1e222b6c6db2782e7a3d989b7cc18f`.
- Исходная сборка Windows использует WPF, конфигурацию `Release`, цель `win-x64` и .NET SDK `10.0.114` из ветки `10.0.1xx`, указанной в CI релиза. Результат публикации — `x64/v2rayN.exe` и `x64/AmazTool.exe`.
- В заголовке показываем версию базы и ревизию VaKoLink из `VaKoLinkRevision` в `v2rayN/v2rayN/v2rayN.csproj`. Первый дистрибутив VaKoLink считается r1. Повышаем ревизию при выпуске нового дистрибутива клиента.

## Решения для следующих этапов

- На главном экране ровно два режима. **Proxy** включает системный прокси и профиль `Surfing + Proxy`. **TUN** включает туннель и профиль `Global + TUN`. При переключении сначала отключается предыдущий режим.
- Используем готовые правила VaKoLink. При отключении или сбое клиент восстанавливает сетевые настройки Windows, которые сам изменил.
- Пользователь активирует подписку один раз через личный кабинет. Возможности v2rayN доступны в расширенных настройках.
- Отдельная кнопка управляет VaKoLink Transport 1.0.4. Для запуска Transport требуется работающий SOCKS5 в режиме Proxy. Перед остановкой или сменой Proxy останавливаем собственный Transport.
- Клиент обновляет подписку и маршруты раз в сутки. Одна кнопка обновляет стабильные Xray, mihomo, sing-box и geoFiles при отключённом VPN. VaKoLink-Client обновляется отдельно.

- В начале описания размещай ссылку на пользовательский ZIP для Windows x64 и инструкцию «Распакуйте архив целиком и запустите `VaKoLink.exe`».

- Описывай только изменения, которые вошли в конкретную версию. При правке опубликованного описания сохраняй ссылки на скачивание, инструкцию по запуску и существующие справочные разделы, в том числе «Что уже есть в VaKoLink» в v1.16.

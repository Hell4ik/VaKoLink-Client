VaKoLink для macOS

Распакуйте ZIP и перенесите VaKoLink.app в «Программы».
Выберите arm64 для Mac с Apple Silicon и x64 для Intel.
Профиль сохраняется в ~/Library/Application Support/VaKoLink.

Это нативная редакция с интерфейсом Avalonia на базе v2rayN 7.25.6.
Доступны подписки, импорт ссылок, системный Proxy и TUN. Для TUN
macOS может запросить пароль администратора. Диагностика и маршрутизация
выбранных приложений из Windows-редакции здесь недоступны.
Обновление приложения устанавливается из ZIP соответствующей архитектуры.

Сборка не нотарифицирована Apple. macOS может запросить подтверждение
первого запуска.

Оригинальный проект 2dust: https://github.com/2dust/v2rayN
Исходники и лицензии находятся рядом с приложением.
